# Diabetes-type-2-prediction-using gene expression data with CNN & Conv-KAN


#Source code accompanying the article **"Diabetes Type 2 Prediction Using Biological Data and Deep Learning"**, published in **Current Bioinformatics** (Bentham Science).

#This repository contains the full implementation used to select disease-relevant genes from public gene expression data and to train and evaluate two deep learning architectures — a baseline **Convolutional Neural Network (CNN)** and a **Convolutional Kolmogorov-Arnold Network (Conv-KAN)** — for predicting Type 2 Diabetes Mellitus (T2DM).
